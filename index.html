1. Connect to GitHub

Ads are saved as config.json in a public GitHub repo, and the game reads that file every minute. To save, this page needs a GitHub token that can write to that one repo. Make a fine-grained token: under Repository access pick Only select repositories and choose the ads repo, then set Contents to Read and write. The token stays in this browser only.

2. In-game ads

Paste or upload an SVG for each spot. Several ads in one spot take turns. Use a viewBox with the shape shown, embed any images inside the SVG as data, and use common fonts or convert text to paths. Scripts and links in SVGs are removed.

3. Google AdMob

Paste your AdMob IDs. The test IDs below are Google's own demo ads: keep them until the app is live on Play Store, and never tap your own real ads. The ad unit IDs change in the game within a minute. The App ID is built into the Android app, so after you change it, run the app build again (see the README).
